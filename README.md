## Sobre o projeto

Este projeto foi desenvolvido como trabalho do primeiro semestre da graduação em **Sistemas de Informação na Universidade Vila Velha (UVV)**.

O objetivo do trabalho é colocar em prática os conhecimentos aprendidos na disciplina de **Construção de Software para Web**, utilizando principalmente **HTML e CSS**.

O projeto consiste em uma **Landing Page pessoal**, apresentando informações sobre minha vida acadêmica, profissional e pessoal, além de serviços de desenvolvimento de sites.



## Conteúdo do site

O site possui cinco páginas:

- **Home** – Apresentação pessoal, vida acadêmica, hobbies, interesses e objetivos profissionais.
- **Currículo** – Formação, cursos, experiências profissionais e conhecimentos.
- **GitHub** – Apresentação do meu perfil e dos meus conhecimentos em desenvolvimento.
- **Serviços** – Serviços de criação de sites e tabela com valores.
- **Contato** – Formulário para solicitação de serviços e envio de informações para orçamento.


Também foram utilizados recursos HTML para:

- Tabelas
- Formulários
- Links internos e externos
- Imagens
- Áudio
- Vídeo
- Listas
- Campos de formulário
- Design responsivo

## Como clonar o repositório

Para baixar uma cópia do projeto para o computador, abra o terminal ou o Git Bash e execute:

git clone https://github.com/rikelmeassis/meu-site.git

Depois, entre na pasta do projeto:

cd meu-site

O projeto também pode ser aberto diretamente pelo arquivo index.html em um navegador.
